# Massive Production of Cancer Synthetic RNA-Seq Gene Expression Samples

This GitHub contains the files related to the article "Massive Production of Cancer Synthetic RNA-Seq Gene Expression Samples", sent to SN Computer Science (http://dx.doi.org/10.1007/s42979-025-04251-3).

Here, the files for training and testing the GAN, the results obtained and the code necessary to generate the results shown in the paper are published.
